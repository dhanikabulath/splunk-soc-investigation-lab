# Atomic Red Team Investigation — T1082

## Incident Summary

Atomic Red Team was used to generate controlled System Information Discovery activity on the Windows lab endpoint.

The test executed `hostname.exe`, generating Sysmon telemetry that was ingested and investigated in Splunk.

## Test Details

- Framework: Atomic Red Team
- Technique: T1082 — System Information Discovery
- Atomic Test: T1082-7 — Hostname Discovery (Windows)
- Endpoint: DC01
- Process: `C:\Windows\System32\HOSTNAME.EXE`

## Initial Detection

Splunk identified fresh `hostname.exe` process activity following execution of the Atomic test.

The process command line showed hostname discovery activity.

## Process Investigation

Sysmon telemetry was used to review the process relationship.

Observed process chain:

`cmd.exe → hostname.exe`

Additional events also showed hostname execution associated with the controlled test environment.

## Surrounding Activity

Telemetry around the Atomic execution was reviewed for additional suspicious behaviour.

The activity observed was consistent with the expected hostname discovery test. No suspicious follow-on activity was identified.

## MITRE ATT&CK

**T1082 — System Information Discovery**

The ATT&CK mapping describes the behaviour generated by the Atomic test.

## Analyst Assessment

**Detection Result: True Positive**

The detection correctly identified System Information Discovery behaviour.

**Incident Verdict: Benign / Controlled Activity**

The activity was intentionally generated using Atomic Red Team. No evidence of unauthorized activity or compromise was identified.

## Escalation Decision

**No escalation required.**

The source and purpose of the activity were known and matched the expected Atomic Red Team test.

In a production environment, unexpected hostname discovery would be reviewed alongside the parent process, user context, surrounding commands and other endpoint activity before deciding whether escalation was required.

## Conclusion

This exercise validated the full workflow from controlled ATT&CK technique execution through Sysmon collection, Splunk detection and analyst investigation.
