# Atomic Red Team Detection — T1082

## Detection Goal

Identify Windows hostname discovery activity using Sysmon process telemetry.

## Data Source

Sysmon process creation events ingested into Splunk.

## Process

`C:\Windows\System32\HOSTNAME.EXE`

## Detection Logic

Search for execution of `hostname.exe` and review the parent process, user and command line for context.

## Severity

Low

## MITRE ATT&CK

T1082 — System Information Discovery

## Analyst Notes

`hostname.exe` is a legitimate Windows utility and should not be treated as malicious by itself.

The detection was validated using Atomic Red Team test T1082-7. Splunk correctly identified the behaviour generated by the test.

The final analyst verdict was benign controlled activity.
